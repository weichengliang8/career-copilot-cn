# Career Copilot CN

面向中文求职场景的半自动求职助手。项目目标不是自动海投，而是帮助求职者从多来源岗位中筛出更真实、更匹配、更值得认真投递的机会。

## 想解决什么

国内求职信息来源分散，岗位质量差异很大。求职者经常需要在 Boss 直聘、猎聘、智联、前程无忧、公司官网、公众号、微信群、内推链接之间来回切换，还要判断岗位是否真实、公司是否靠谱、简历怎么改、开场白怎么写、进度怎么记录。

Career Copilot CN 的第一目标是做一个本地优先的求职工作台：

- 多来源岗位统一导入
- 公开来源职位检索
- 岗位匹配度评分
- 岗位可信度和风险提示
- 简历修改建议
- Boss/猎聘式短开场白生成
- 投递状态看板
- 面试准备记录

## MVP 功能

- 粘贴岗位 JD，提取岗位关键信息
- 从 GitHub Issues 和 V2EX Jobs 检索公开招聘信息
- 录入公司、岗位、薪资、城市、来源链接
- 根据个人资料生成匹配分析
- 根据规则识别虚高薪资、培训贷、外包模糊、收费等风险信号
- 生成 HR 追问清单和开场白
- 保存投递状态：待评估、准备投递、已投递、已沟通、已约面、Offer、不合适

## 当前原型

第一版原型包含一个本地服务和网页界面：

```bash
npm start
```

然后打开：

```text
http://localhost:5173
```

当前支持从 GitHub Issues 和 V2EX Jobs 这类公开来源检索职位，并把结果导入岗位池。后续可以升级成 React/Next.js + SQLite + AI 接口。

## 设计原则

1. 人工确认优先：不自动登录、不自动聊天、不自动投递。
2. 证据透明：可信度结论必须说明依据。
3. 本地优先：简历、联系方式、投递记录默认保存在本地。
4. 多来源统一：平台只是来源，核心是统一岗位池。
5. 不编造经历：AI 只能改写和突出已有经历，不能虚构项目。

## 注意

本项目不鼓励绕过招聘平台限制，也不建议自动批量投递。它的定位是求职决策和材料准备助手，而不是账号自动化工具。
